Every row follows: **symptom → likely cause → safe command → remediation**.

## First boot

| Symptom | Cause | Check / remediation |
| --- | --- | --- |
| API container exits immediately | Invalid config | `docker compose logs api` — the message names the missing/weak variable and the exact command to generate it |
| `/setup` never finishes | `/api/v1/config` unreachable | `curl http://localhost:3000/api/v1/config`; fix the `web` proxy or API logs |
| `setup_token_required` | Wrong token | Re-paste; tokens compare byte-wise (constant-time) |
| `setup_in_progress` | Concurrent claim | Wait for the claim TTL, retry |
| Missing-table 503 | Migrations not run | `docker compose … up migrate` |
| Config endpoint reports `setupRequired: true` forever | Database unreachable | `docker compose logs api`; check `db` health |

## Sign-in & accounts

| Symptom | Cause | Check / remediation |
| --- | --- | --- |
| Verification email never arrives | No mail channel | API log prints the link (log-only mode); configure SMTP/Resend — [Mail](/docs/self-hosting/configuration/email) |
| Verification link 404 | `PUBLIC_URL` mismatch | `BASE_URL`/`PUBLIC_URL` must be the external origin — [Reverse proxy & TLS](/docs/self-hosting/configuration/domains-tls) |
| Social buttons hidden | Provider not configured | `GET /api/v1/config` → `providers`; set both id **and** secret |
| `weak_password` | Policy | Minimum 8 characters |
| Can't create a project | Email unverified | The banner links to resend verification |

## Realtime & ingestion

| Symptom | Cause | Check / remediation |
| --- | --- | --- |
| Realtime never connects | Proxy drops upgrades | Pass `Upgrade`/`Connection` for `/ws` |
| WebSocket closes immediately | Bad service JWT | Clock skew, or `AUTH_BASE_URL` unset in the analytics service |
| `429` responses | Per-IP rate limit | Ingestion 120/min, ws 30/min, auth 20/min; add a shared limiter at the proxy for replicas |
| Sessions recorded, map empty | No Mapbox token | Set `VITE_MAPBOX_ACCESS_TOKEN` in the web build |
| No geo data | Enrichment unavailable | Optional; configure `IP_INFO_API_TOKEN` or accept null geo fields |

## Storage

| Symptom | Cause | Check / remediation |
| --- | --- | --- |
| Avatar upload fails `file_not_found` | Multipart field name | The dashboard sends `file`; direct callers must use the same field |
| Upload rejected | Validation | Max 5 MB; jpeg/png/gif/webp/heif/heic by MIME **and** magic bytes |
| S3 driver boot failure | Missing vars | Message names the exact variable — [Storage](/docs/self-hosting/configuration/file-storage) |

## Data & operations

| Symptom | Cause | Check / remediation |
| --- | --- | --- |
| Analytics reads empty | Store unreachable/unconfigured | Rest of the instance keeps working by design; restore the `sqld` volume |
| Events list stops at 200 | Product behavior | The dashboard shows the latest 200 events — not a fault |
| Dashboard shows stale data | WebSocket disconnected | Reload; check `/ws` in DevTools and the proxy upgrade headers |

## Diagnostics to run first

```sh
docker compose --env-file deploy/compose.env -f deploy/compose.yml ps
docker compose --env-file deploy/compose.env -f deploy/compose.yml logs -f api
curl -fsS http://localhost:3000/health/live
curl -fsS http://localhost:3000/health/ready
curl -fsS http://localhost:3000/api/v1/config
```
