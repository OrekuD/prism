<SectionLabel label="PACKAGE: @prism/react" />

`@prism/react` is a THIN adapter over an already-created, READY client. It
never creates a second queue, session, envelope, consent store, or retry
policy — ownership stays with whoever called `createBrowserClient` (or
`createPrismClient`), which keeps non-React ownership and cleanup explicit.

```tsx
// client.ts — create it ONCE, outside React
import { createBrowserClient } from "@prism/browser";
export const prism = await createBrowserClient({
  projectKey: "pr_xxx",
  endpoint: window.location.origin,
  collection: { initialState: "granted" },
});

// App.tsx
import { PrismProvider, usePrism } from "@prism/react";

root.render(
  <PrismProvider client={prism}>
    <App />
  </PrismProvider>,
);

function CheckoutButton() {
  const { track } = usePrism(); // stable bound method
  return <button onClick={() => track("checkout-started", { value: 42 })}>Checkout</button>;
}
```

## The provider

- Accepts a **ready client** (never an initialization config) — no
  half-initialized context.
- Registers **no effects, listeners, or timers** — React Strict Mode
  double-mounting can never duplicate work.
- Is **not** an error boundary or an exception SDK; it performs no
  console-only error handling.

## `usePrism()`

Returns a stable facade over the client: `track`, `startSession`,
`setCollectionState`, `flush`, `shutdown`, `onDiagnostic`,
`collectionState`, plus the raw `client`. Bound methods keep their identity
across renders — no recreated callbacks. Throws a specific error outside a
provider.

Automatic route/page tracking is a later task; capture page identity
explicitly with `capturePageContext()` from `@prism/browser`.
