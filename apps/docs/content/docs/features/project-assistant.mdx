Every project opens on its **Overview** page, which pairs a project
summary with the assistant: ask a question in the composer and the
answer links back to the measured facts behind it, so a conclusion can
lead you to the underlying activity.

- Conversations belong to the project and persist — reopen one from
  the conversation switcher to continue where you left off.
- Start a fresh chat any time from the **agent** view.
- The assistant reads the same events, sessions, people, and errors
  the dashboards show; it cannot see other projects or workspaces.

Use it for "what changed" questions — after a release, a traffic
shift, or a new error issue — then follow the linked facts into
[Events](/docs/features/capturing-events),
[Web analytics](/docs/features/page-analytics), or
[Error tracking](/docs/features/error-tracking) for the full context.
