Prism keeps four metrics distinct so one number never gets labeled as
another. The definitions below match the API exactly.

## The four totals

- **Events** — event occurrences: one stored row per accepted event.
- **People** — unique resolved people: distinct `person_id` values.
- **Anonymous identities** — distinct `anonymous_id` values, whether or
  not they are linked to a person.
- **Sessions** — distinct `session_id` values.

These are available from the [honest totals endpoint](/docs/reference/api/analytics-queries).
The dashboard shows the sessions and events numbers; people and anonymous
identities are visible on the people pages.

## Breakdowns

Breakdowns group events by one dimension with bounded cardinality
(100 keys maximum):

- **event** — event name;
- **person** — resolved person;
- **session** — session, counted by events in that session;
- **context kind** — the `kind` context field (for example `web` or
  `mobile`);
- **context platform** — the `platform` context field.

## What Prism does not report yet

Prism does not have funnels, retention reports, cohorts, or trend charts.
The sidebar shows only capabilities that exist in the product.
