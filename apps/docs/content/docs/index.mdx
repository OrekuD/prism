Welcome to the Prism documentation. Prism is product analytics for teams
that build with explicit events, client-owned sessions, and
developer-supplied identities: a runtime-neutral SDK core, a browser
SDK, thin React bindings, and a dashboard for sessions, events, people,
page analytics, and errors.

Start with the [Quickstart](/docs/start/quickstart) — create an account,
connect a source, and see your first event in minutes.

## Documentation

- **Start** — the quickstart and the complete JavaScript and React SDK
  setup.
- **Features** — one canonical guide per feature: capturing events,
  page analytics, identifying users, sessions and live activity, and
  error tracking.
- **Configuration** — projects, sources, and keys; consent and privacy;
  delivery and diagnostics.
- **Self-hosting** — run the whole stack with Docker Compose, plus the
  operating reference.
- **Reference** — packages, exact limits, and the runtime adapter
  contract.
