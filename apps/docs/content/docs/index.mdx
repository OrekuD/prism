Welcome to the Prism documentation. Prism is product analytics for teams
that build with explicit events, client-owned sessions, and
developer-supplied identities: a runtime-neutral SDK core, a browser
runtime adapter, thin React bindings, an ingestion service, and a
dashboard for sessions, events, and people.

Start with the [overview](/docs/getting-started/overview) to understand
the product boundary and data flow, or pick your path directly:

- [Hosted quickstart](/docs/getting-started/hosted-quickstart) — create
  an account, connect a project, and see your first event in minutes.
- [Self-hosted quickstart](/docs/getting-started/self-hosted-quickstart)
  — run the whole stack with Docker Compose on your own infrastructure.
- [Choose hosted or self-hosted](/docs/getting-started/choose-deployment)
  — compare the two modes.
