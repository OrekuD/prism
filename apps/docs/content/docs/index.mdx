Welcome to the Prism documentation. Prism is realtime product analytics for
teams: a lightweight browser SDK, a high-throughput ingestion service, and a
dashboard for sessions, events, and projects.

Start with the [overview](/docs/start/overview) to understand the product
boundary and data flow, or pick your path directly:

- [Hosted quickstart](/docs/hosted/quickstart) — create an account, connect
  a project, and see your first event in minutes.
- [Self-hosting evaluation](/docs/self-hosting/evaluation/overview) — run
  the whole stack on your own infrastructure.
- [Hosted or self-hosted](/docs/start/choose) — compare the two modes.
