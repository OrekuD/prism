# React Native SDK

> Task 18 slice 9 scaffold.

Install `@prism-analytics/react-native`, create a source with platform `react-native`, use the publishable source key. Supports Expo + bare, AsyncStorage, AppState, React Navigation / Expo Router adapters. Screen views are `$prism_screen_view` reserved records; app sessions are foreground active-time; installations are observed digests. JS errors via Task 15 lane.
