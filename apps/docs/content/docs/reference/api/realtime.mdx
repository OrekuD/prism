The realtime stream delivers live session activity to the dashboard over
a WebSocket at `/ws`.

## Connecting

The client opens a WebSocket to the public origin (`/ws`) and sends one
message:

```json
{ "type": "connect-project", "data": { "projectId": "…", "token": "…" } }
```

The token is a short-lived service JWT issued by the product API. The
analytics service verifies it against the published JWKS (issuer,
audience, signature, expiry), checks that the subject is an active user,
and authorizes the subscription through project and team membership. A
socket is always subscribed to exactly one project; malformed payloads
close the socket.

## Pushed messages

```json
{ "type": "session-started", "data": { "session": { "sessionId": "…", "projectId": "…", "startedAt": 1723456789012, "lastSeenAt": 1723456789012, "anonymousId": null, "context": null, "isOnline": 1 } } }
```

Session resources carry no raw IP or coordinates. The message is emitted
for accepted (non-duplicate) `session_started` events; a failing socket
never disrupts delivery to healthy clients.

## Closure

The server closes the socket when authentication fails or the payload is
malformed. Clients should reconnect with a fresh service token on close.
