All query endpoints are authenticated, team/project-authorized, and
scoped by the project BEFORE filtering or pagination. The project is
derived from the slug, and membership is verified against the team.

## People list

`GET /api/v1/projects/:slug/people`

| Query | Description |
| --- | --- |
| `cursor` | Opaque keyset cursor for the next page |
| `limit` | Page size (default 50, max 100) |
| `q` | EXACT external-ID match only — no prefix or fuzzy search |
| `traitKey` + `traitValue` | Exact match on an indexed safe trait |

Returns `{ people, nextCursor }` with honest counts per person: event
occurrences, DISTINCT sessions, identity links, first/last seen, and
current traits.

## Person detail

`GET /api/v1/projects/:slug/people/:personId`

Returns traits, linked external and anonymous identities, and first/last
seen. `404` for an unknown person.

## Person activity

`GET /api/v1/projects/:slug/people/:personId/activity?limit=`

A bounded, chronological event timeline (newest first; default 200).

## Export

`GET /api/v1/projects/:slug/people/:personId/export`

Documented analytics data only: identity references, traits, sessions,
and events. Never keys, tokens, raw IPs, or other users' data.

## Deletion

`DELETE /api/v1/projects/:slug/people/:personId?confirm=true`

Destructive. Removes links, traits, events, and the person atomically.
Idempotent retries are safe. Without `confirm=true` the API returns
`confirmation_required`.

## Filtered events

`GET /api/v1/projects/:slug/events/filtered`

| Query | Description |
| --- | --- |
| `from` / `to` | `received_at` range (epoch ms) |
| `name` | Exact event name |
| `personId` | Exact person |
| `sessionId` | Exact session |
| `propertyKey` + `propertyValue` | Exact safe-property match |
| `limit` | Page size (default 200, max 500) |

## Totals

`GET /api/v1/projects/:slug/totals`

Returns four DISTINCT metrics: `events`, `people`, `anonymousIdentities`,
and `sessions`. These numbers are never conflated.

## Breakdowns

`GET /api/v1/projects/:slug/breakdown?dimension=`

Supported dimensions: `event`, `person`, `session`, `context-kind`,
`context-platform`. Bounded to 100 keys, ordered by count descending.

## Error behavior

Malformed stored JSON is quarantined to `null` at the boundary — it never
crashes a response. Errors use coarse codes (`project_not_found`,
`person_not_found`, `invalid_dimension`, `confirmation_required`) with no
database details.
