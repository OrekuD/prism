All ceilings below are shared between the SDK and the server: an
official-SDK event is never rejected by the ingestion server for rules
the SDK already enforces.

## Event names

- Non-empty, at most 128 characters.
- No control characters.

## IDs

- Event IDs: client-generated, 1–128 characters.
- External user IDs: opaque strings, 1–256 characters, no control
  characters. Not required to look like email addresses.
- Anonymous IDs: SDK-generated, 1–128 characters.

## Properties and traits

- Strict JSON values only: no functions, symbols, bigint, non-finite
  numbers, dates, class instances, accessors, or cycles.
- Dangerous keys rejected: `__proto__`, `constructor`, `prototype`.
- Depth at most 12; strings at most 10 000 characters.
- Credential-like keys are redacted server-side (`[REDACTED]`) — the
  deny list covers keys such as password, token, apiKey, and
  authorization.
- Trait keys: 1–128 characters, no control characters.

## Sizes

| Ceiling | Value |
| --- | --- |
| Events per batch | 50 |
| Request body | 512 KiB (enforced while streaming) |
| Single event | 32 KiB |
| Queue events (SDK) | 1 000 |
| Queue bytes (SDK) | 1 MiB |
| Batch bytes (SDK) | 256 KiB |

## Time

- `occurredAt` must not exceed 24 hours future skew and not be older
  than the documented window; the server rejects unreasonable
  timestamps with `invalid-timestamp`.
- SDK timeouts: `requestTimeoutMs` (default 10 s), `flushIntervalMs`
  (default 10 s), retries (default 5, exponential backoff with jitter).

## Queries

- People page size: default 50, max 100.
- Activity: default 200 events.
- Filtered events: default 200, max 500.
- Breakdowns: at most 100 keys.
- Export: bounded to 500 events.

## Rate limits

- Ingestion: 120 requests per minute per IP, plus an event-weighted
  per-project quota. Exceeded requests get `429` with `Retry-After`.
- WebSocket upgrades: 30 per minute per IP.

## Authentication input

- Analytics keys: `Bearer` scheme with an exact single-token match.
- Service JWTs: verified against the published JWKS.
