This quickstart takes you from a Linux host to a verified event in about
fifteen minutes. Docker Compose is the only officially documented
deployment method. For a full evaluation of the topology, storage, and
configuration, see [Requirements](/docs/self-hosting/requirements) and
[Architecture](/docs/self-hosting/architecture) first.

## Before you start

You need a Linux host with Docker and the Compose plugin installed.
See the [requirements checklist](/docs/self-hosting/requirements) for
hardware guidance, ports, and secrets.

## 1. Copy and complete the environment file

Prism ships a template with safe defaults for local evaluation.

```sh
cp deploy/compose.env.example deploy/compose.env
```

Edit `deploy/compose.env` and set at least:

- `PUBLIC_URL` to your public origin (for example `https://prism.example.com`).
- `JWT_SECRET_KEY` to a long random value.
- `SETUP_TOKEN` to a long random value.

Generate secrets with `openssl rand -hex 32` and paste them into the file.

## 2. Start the stack

```sh
docker compose --env-file deploy/compose.env up -d --build
```

Compose starts the product API, the analytics API, PostgreSQL, sqld, and
the public nginx origin. The product API runs its forward-only migrations
before serving, and the analytics API applies its own migration journal at
startup.

## 3. Check liveness and readiness

```sh
curl -fsS http://localhost:3000/health/live
curl -fsS http://localhost:3000/health/ready
```

`/health/ready` returns 200 only when both the product database and the
migrated analytics store are available.

## 4. Create the first owner

Open `/setup` in a browser and enter the setup token from
`deploy/compose.env`. The first account becomes the instance owner; the
setup endpoint then closes and refuses further claims.

## 5. Create a project and send a test event

1. Create a project under your personal team.
2. Copy its analytics key from **Project → Settings → API keys**.
3. In a browser console on the same origin, run:

```ts
import { createBrowserClient } from "@prism/browser";

const prism = await createBrowserClient({
  sourceKey: "psk_…",
  endpoint: window.location.origin,
  collection: { initialState: "granted" },
});
prism.startSession();
prism.track("quickstart_event", { source: "self-hosted" });
```

The event appears on the project's **Events** page, and the session
appears on **Realtime**.

## Next steps

- Configure [environment variables](/docs/self-hosting/configuration/environment-variables) for production.
- Set up [TLS and a reverse proxy](/docs/self-hosting/configuration/domains-tls) before exposing the origin.
- Plan [backups and restores](/docs/self-hosting/operations/backup-restore) before collecting real data.
