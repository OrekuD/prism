<SectionLabel label="FIVE MINUTES TO FIRST EVENT" />





## 1. Create an account


<Callout type="info" title="Hosted">
This quickstart covers the hosted product. Self-hosting follows the same
SDK steps but starts from the `/setup` first boot — see
[Self-hosting](/docs/self-hosting/overview).
</Callout>


Open the dashboard, choose **Create account**, and sign up with your email and
a password (minimum 8 characters). GitHub and Google sign-in appear when the
hosted deployment has them enabled.

You must **verify your email** before you can create a project: check your
inbox, open the confirmation link, and return to the dashboard. The
verification banner in the dashboard shows a **Resend** link if the email
didn't arrive.

## 2. Create a project

From the projects page, create a team, then a project with a name and slug.
The project's analytics key is generated automatically.

## 3. Copy the analytics key

Open **Project → Settings → API keys** and copy the key. It is a public,
write-only identifier — safe to embed in your site's JavaScript.

## 4. Install the SDK

```sh
npm install @prism/core
```

## 5. Start tracking

```ts
import { createPrismClient } from "@prism/core";

const prism = await createPrismClient({
  sourceKey: "psk_xxx",
  endpoint: window.location.origin,
  runtime,
  collection: { initialState: "granted" },
});
```

The factory resolves to a ready client — no automatic side effects.
`startSession()` starts a client-owned session explicitly.

## 6. Log an event

```ts
prism.track("button-click", { label: "signup" });
```

## 7. See it live

Open **Project → Realtime** — new sessions appear as live rows the moment
they start (the v2 model carries no coordinates; the map is decorative).
Logged events appear on the **Events** dashboard.
