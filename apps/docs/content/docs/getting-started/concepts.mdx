Prism organizes data around a small set of concepts. Each definition
links to the guide that explains its full behavior.

## Projects

A project is the unit of analytics: one analytics key, one set of events,
sessions, and people, one realtime stream. Projects belong to a team, and
creating one requires a verified email address.

## Analytics keys

Every project has a public analytics key shown under **Project →
Settings → API keys**. It is a public identifier — the browser SDK embeds
it in your site's JavaScript — and it can only write analytics data. The
project is derived from the key on every ingestion request; client
ownership fields are ignored.

## Events

Named events with optional structured properties, captured explicitly
with `track()`. See [Track events](/docs/tracking/events).

## Sessions

A session is one visit with a client-owned ID: the SDK generates it
locally and emits `session_started` and `session_ended` events. See
[Manage sessions](/docs/tracking/sessions) and
[Sessions and realtime](/docs/analytics/sessions-realtime).

## Anonymous IDs and people

An anonymous ID is an SDK-generated identity for an origin. A person is a
resolved analytics subject, created by an explicit `identify()` call with
your external user ID. See [Identify people](/docs/tracking/identity) and
[People and profiles](/docs/analytics/people).

## Traits and global properties

Traits are explicitly supplied profile attributes attached to a person.
Global properties are client-scoped values merged into every event. See
[Identify people](/docs/tracking/identity) and
[Set global properties](/docs/tracking/global-properties).

## Teams

Teams own projects. The team creator is the owner; members join through
invitations. See [Teams and invitations](/docs/management/teams).

## Realtime

Live sessions stream to the dashboard over an authorized WebSocket. See
[Sessions and realtime](/docs/analytics/sessions-realtime).

## The SDK layers

| Package | Role |
| --- | --- |
| `@prism-analytics/core` | The runtime-neutral engine — events, identity, consent, queueing, retries, diagnostics, delivery |
| `@prism-analytics/browser` | Browser transport, storage, lifecycle, and context |
| `@prism-analytics/react` | A thin provider and hook over an existing client |

See [SDK overview](/docs/tracking/overview).
