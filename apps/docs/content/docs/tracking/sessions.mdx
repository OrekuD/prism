<SectionLabel label="SESSIONS" />

Sessions are client-owned in v2: the SDK generates the session ID locally and
emits `session_started` / `session_ended` events through the standard batch
ingestion — there is no server round-trip before events are accepted.

```ts
const handle = prism.startSession({ properties: { plan: "pro" } });
// queue: session_started with the client-owned session ID

prism.track("checkout", { step: 2 }); // sessionId attached automatically

handle.end();
// queue: session_ended — the second call returns { status: "not-active" }
```

Sessions appear as live rows on the project realtime page and are stored in
the v2 session model with start/end/last-seen timestamps and normalized
context (no raw IP, no approximate coordinates).
