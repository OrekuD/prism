Global properties attach to every event without repeating them on each
`track()` call. Use them for stable context such as plan, region, or
referral source.

## Scopes

Each property lives in one explicit scope.

- **memory** (default) — lives for the client lifetime.
- **session** — survives reloads in the same execution context (per tab
  in the browser).
- **persistent** — survives across launches; requires the runtime
  storage adapter.

```ts
await prism.setGlobalProperty("theme", "dark");                  // memory
await prism.setGlobalProperty("referral", "friend", "session");  // session
await prism.setGlobalProperty("plan", "pro", "persistent");      // persistent
```

## Precedence

Merged properties follow `persistent < session < memory`, and per-event
properties override ALL globals for that event without mutating the
stored globals:

```ts
await prism.setGlobalProperty("plan", "pro");
prism.track("checkout", { plan: "enterprise" });
// the event carries plan: "enterprise"; the stored global stays "pro"
```

## Removing properties

```ts
await prism.unsetGlobalProperty("theme");
await prism.clearGlobalProperties();          // all scopes
await prism.clearGlobalProperties("session"); // one scope
```

## Validation and failures

Keys are 1–128 characters without control characters; dangerous keys
(`__proto__`, `constructor`, `prototype`) are rejected, and values must
be strict JSON. Persistent writes go through the storage adapter; a
storage failure keeps the in-memory value stable and emits a coarse
diagnostic — it never rejects the call's state.

## Reset

`reset()` clears every global-property scope together with the identity
state, so the next user on a shared device never inherits the previous
user's properties.
