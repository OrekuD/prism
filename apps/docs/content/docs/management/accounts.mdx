The **Profile** section covers:

| Page | What you can do |
| --- | --- |
| General | Change your name and username |
| Security | Change your password |
| Authentication | See the email you signed up with and which social providers are linked |
| Teams | Switch teams, create teams, view memberships |

## Username

Update your name and username from **Profile → General**. Usernames are
stored on your account and shown to teammates in the team switcher and
member lists; they are not globally unique.

## Avatar

`PUT /api/v1/user/update-profile-picture` uploads an avatar. Storage is
driver-based (task-6 object storage):

- **Hosted**: ImageKit;
- **Self-hosted**: local filesystem (`/files/*`) by default, S3-compatible
  endpoints, or ImageKit.

Avatar uploads validate the file before storing (size and image checks) —
see [Storage](/docs/self-hosting/configuration/file-storage).

## Password changes

Changing your password requires the current password and a new password of at
least 8 characters. The auth API enforces the minimum; the UI reports
`weak_password` inline.

## Deleting your account

There is no self-service account deletion today. Contact the operator of your
instance (hosted: Prism support; self-hosted: your admin) for account
removal.
