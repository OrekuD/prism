## What is Prism?

Prism is a self-hostable analytics platform with real-time WebSocket
delivery, session tracking, and a lightweight browser SDK.

- **Sessions** — every visit is recorded with country, OS, browser, device
  type, referrer, and coordinates.
- **Realtime** — new sessions appear on a live map the moment they start.
- **Events** — log named events with structured data from your site.
- **Teams** — invite teammates, create projects, and scope access per team.

## Architecture

<CardGrid stagger>
	<Card title="Web dashboard" icon="seti:react">
		React + Vite dashboard for teams, projects, sessions, events, and
		settings.
	</Card>
	<Card title="Main API" icon="cloud">
		A Cloudflare Worker: auth, teams, projects, and profile APIs backed by
		Neon (Postgres).
	</Card>
	<Card title="Analytics API" icon="activity">
		A Node/Hono service that ingests sessions and events into Turso and
		pushes live updates over WebSockets.
	</Card>
	<Card title="Browser SDK" icon="seti:javascript">
		`@prism/core` — one line to start tracking a session, plus event
		logging with a browser-safe session end.
	</Card>
</CardGrid>
