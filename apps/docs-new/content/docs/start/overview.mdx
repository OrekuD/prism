Prism is realtime product analytics for teams: a lightweight browser SDK, a
high-throughput ingestion service, a WebSocket delivery channel, and a
dashboard for sessions, events, and projects.

The same codebase runs in two deployment modes:

- **Hosted** — Prism operates the product API, analytics ingestion, and
  database; you sign in and create a project.
- **Self-hosted** — you run the full stack (web, API, analytics, PostgreSQL,
  analytics store) on your own infrastructure, with no outbound network
  access at runtime.

Both modes share the SDK, ingestion protocol, and dashboard. Choose a path on
[Hosted or self-hosted](/docs/start/choose).

## Product boundary

Prism records **sessions** and **events** for projects you create, and
delivers new sessions to the dashboard over a WebSocket connection in
realtime. It does not:

- track users across projects or sites (each project is an isolated silo);
- sell, export, or share your data with third parties;
- require a Prism account for self-hosted deployments;
- send data anywhere outside your instance (self-hosted runtime egress is
  blocked by the default Compose network).

## Data flow

Prism runtime data flow:

1. **Browser SDK (`@prism/core`)** — posts sessions and events to the
   analytics API.
2. **Analytics API (ingestion + WebSocket)** — validates and stores them,
   enriches sessions with best-effort geo data, and pushes new sessions to
   the dashboard over WebSocket.
3. **Analytics store (sessions & events)** — the write path for ingestion;
   read by the product API.
4. **Product API (dashboard + auth)** — serves the dashboard, auth, teams,
   projects, and analytics reads.
5. **Product database (PostgreSQL)** — users, teams, projects, keys.
6. **Dashboard (web app)** — the React dashboard.

The SDK authenticates with the **project analytics key** — a public write-only
identifier. The dashboard authenticates with an **HTTP-only session cookie**
against the product API. Realtime subscriptions authenticate with a
**short-lived service JWT** verified against the product API's JWKS endpoint.

## Maturity

Prism is under active development. The SDK, ingestion, dashboard, auth, and
self-hosting stack are implemented and covered by tests; anything documented
as `planned` is not yet available. See [Core concepts](/docs/start/concepts)
for the vocabulary, and the [security model](/docs/operations/security) for
current boundaries.
