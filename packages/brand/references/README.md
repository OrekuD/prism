# Prism logo direction reference

`prism-mark-final-reference.png` is the approved visual direction for the
Prism mark. It is a square, transparent RGBA reference generated from the
concept selected by the project owner.

The approved geometry is a two-piece folded-prism silhouette:

- an off-white upper polygon;
- a violet lower polygon;
- a narrow diagonal negative-space gap between them.

There are no input/output beams, enclosing shapes, letters, gradients, shadows,
or glass effects in the production design. Subtle shading in the generated PNG
is generation residue, not part of the intended mark.

This PNG is a direction reference only. The Task 7 implementation agent must
rebuild the mark manually as clean vector paths on a square artboard, using
`#F2F2F4` and `#6547E8`. Do not auto-trace the PNG or ship it as the canonical
production logo.

The built-in image generator created the reference from the user-supplied
selected concept. A temporary green chroma-key background was removed locally;
the checked-in file has an alpha channel and transparent corners.
